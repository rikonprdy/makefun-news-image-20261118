A program that writes one image summing up Wednesday 18 November 2026: Trump's arrival in Shenzhen for a historic trilateral with Xi and Putin, Ukraine's strike on the Crimean Bridge, the Gulf standoff, Israel's Gaza operation, the Alaska Senate race, and the Siberia air crash — drawn as a one-page newspaper front page. The image is stored in `main.ts` (drawn by `tools/generate-entry.py` from wire reports of the day) and the program writes it out byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
